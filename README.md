   - ಕಾರ್ಡ್‌ನ ಹೊರಗೆ ಎಲ್ಲಿಯಾದರೂ ಕ್ಲಿಕ್ ಮಾಡಿದರೂ ಅಥವಾ ಕೀಬೋರ್ಡ್‌ನಲ್ಲಿ **[Escape]** ಒತ್ತಿದರೂ ತಕ್ಷಣ ಕಾರ್ಡ್ ಮುಚ್ಚಿ ಗೇಮ್ ರಿಸ್ಯೂಮ್ ಆಗುತ್ತದೆ.
